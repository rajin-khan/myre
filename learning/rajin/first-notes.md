# First notes

We're making myre to learn how an operating system fits together. The first steps are simple: learn one thing, try one small change, and write down what happened.

## Questions to start with

- What does the kernel actually do?
- What happens between pressing the power button and seeing a desktop?
- Which parts of an Arch-based system can we safely change first?
