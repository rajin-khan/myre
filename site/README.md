# myre

myre is a for-fun operating-system project by groceryboix. We're learning how computers work by building small things together and taking the time to understand them.

The long-term idea is an Arch-based Linux system with strong gaming support. We'd love myre to stand alongside, or maybe even improve on, projects like Bazzite. That's a big someday goal. For now, we're here to learn and enjoy making things work.

![myre banner](banner.png)

## Site files

- `index.html` is the project vision board.
- `app.js` powers the expandable learning hub. Video links and checkmarks are saved in the current browser only.
- `learning/` contains the Markdown notes shown in the hub, grouped by what we're learning, testing, and making.
- `banner.html` and `banner.css` make the screenshot-ready banner.
- `banner.png` is the supplied 2644 × 1692 banner artwork.
- `styles.css` styles the vision board.
