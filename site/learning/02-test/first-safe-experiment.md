# Our first safe experiment

Good experiments change one thing at a time and leave a way back.

For a first try, use a virtual machine instead of a computer you depend on. Take a snapshot before changing anything, write down what you expect to happen, make one small change, then compare the result with your guess.

Do not run commands you do not understand with administrator privileges. If a step could erase files or change a real machine, stop and ask the group before trying it.

## Make a note

- What did you expect?
- What changed?
- What surprised you?
- How would you undo it?
