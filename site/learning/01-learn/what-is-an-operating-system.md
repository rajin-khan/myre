# What is an operating system?

An operating system is the main software that helps people and programs use a computer.

It starts other programs, keeps track of files, shares the machine's memory and processor time, and talks to hardware such as the keyboard, screen, and storage drive.

Linux is a kernel and a family of systems built around it. Arch Linux is one such system. myre is our project to learn how the pieces fit together before we try making our own choices.

## Talk it through

- What does the operating system do when an app asks to open a file?
- Which parts of that work could an app do itself, and which parts should the operating system handle?
- Name one thing you use on your computer that is not part of the operating system.
