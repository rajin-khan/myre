# myre

![myre banner](site/banner.png)

myre is a for-fun operating system project by groceryboix. We want to learn how computers work, try things ourselves, and keep building from what we learn.

We're starting small. The long-term idea is an Arch-based Linux system that feels good to use and plays games well. Maybe one day it can hold its own next to projects like Bazzite. For now, we're taking our time and making things together.
